# Sales Analysis Using SQL Server

## Project Overview

This project uses SQL Server to analyze sales data and understand sales, customer, product, and salesperson performance.

The project covers data profiling, data quality checks, sales analysis, customer analysis, product and category performance, salesperson performance, and practical SQL techniques including joins, aggregations, and window functions.

---

## Business Objectives

The analysis focuses on answering questions such as:

* How much total sales has the business generated?
* Which products and categories generate the most sales?
* How are sales distributed across products and months?
* Which customers generate the most sales?
* Which countries generate the most sales?
* How many orders does each customer have?
* How do salespeople perform based on total sales?
* How does sales performance change from month to month?
* How can customers and orders be ranked or segmented using SQL?

---

## Database Structure

The analysis uses the following tables:

* `Sales.Customers`
* `Sales.Employees`
* `Sales.Products`
* `Sales.Orders`
* `Sales.OrdersArchive`

The `Orders` table acts as the main transaction table and is connected to customers, products, and salespeople through their respective IDs.

## Analysis Performed

### 1. Data Profiling & Data Quality

The project begins by understanding the dataset and checking its quality.

The analysis includes:

* Record counts across tables
* NULL value checks
* Duplicate `OrderID` checks in `OrdersArchive`
* Investigation of duplicate records using `CreationTime`

---

### 2. Sales Analysis

Sales performance is analyzed through:

* Total sales
* Sales by product
* Product contribution to total sales
* Monthly sales
* Monthly contribution to total sales
* Top-selling product
* Sales categorization into High, Medium, and Low
* Month-over-month sales performance

---

### 3. Customer Analysis

Customer behavior and contribution are analyzed through:

* Total sales generated by each customer
* Number of orders per customer
* Sales by country
* Customer ordering frequency
* Customers with the lowest total sales

---

### 4. Product Analysis

Product performance is analyzed through:

* Top-selling products
* Sales by category
* Category contribution to total sales
* Lowest and highest individual sales by product

---

### 5. Salesperson Analysis

Salesperson performance is evaluated based on:

* Total sales generated by each salesperson

---

### 6. SQL Techniques

The project demonstrates practical use of:

### 7. Window Functions

Window functions are used for practical analytical tasks including:

* `ROW_NUMBER()`
* `RANK()`
* `DENSE_RANK()`
* `NTILE()`
* `LAG()`
* `LEAD()`
* `FIRST_VALUE()`
* `LAST_VALUE()`

Use cases include:

* Top-N analysis
* Bottom-N analysis
* Duplicate identification
* Data segmentation
* Month-over-month analysis
* Customer ordering analysis
